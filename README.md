# Operations & Risk Intelligence Dashboard (Tableau)

## Overview
This project analyzes operational performance and risk using Tableau.
It helps identify underperforming regions, high-risk products, and
the impact of discounts and returns on profitability.

## Tools Used
- Tableau Public
- Excel / CSV
- Data Visualization & Analytics

## Key Features
- Interactive KPI dashboard
- Sales & Risk map
- Risk heatmap
- Discount vs Profit analysis
- Underperforming region identification

## Outcome
Provides data-driven insights for business decision-making.
